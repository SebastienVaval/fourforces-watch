Open endpoints

  • /api/observations?force=water|air|land|fire: every observation in one common schema
  • /api/geojson: GeoJSON FeatureCollection
  • /api/cap: watch/alert items as OASIS CAP 1.2 XML
  • /api/board: neighborhood Hazard Board
  • /api/status: feed health
  • /api/overlays: county open-data map overlays (GeoJSON at /api/overlays/<id>)
  • /docs: interactive API docs

Camera snapshots: FL511 / Florida DOT, shown by direct link and analysed in memory only (never stored). Tide: NOAA CO-OPS. Gauges: USGS. Alerts: NWS. Storms: NHC. Disasters: OpenFEMA. Evacuation zones, storm surge planning zones, FEMA flood zones, canals, evacuation routes, fire stations, hospitals, cooling centers, hurricane bus pickups and urban heat islands: Miami-Dade County Open Data. Basemap: Mapbox (when configured) or OpenStreetMap / CARTO. AI: Grok via the xAI API.
